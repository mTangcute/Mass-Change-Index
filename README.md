# Mass-Change-Index (MCI)
MATLAB scripts for generating the Mass Change Index (MCI) from Line-of-Sight Gravity Difference (LGD) measurement and its climatology.

The MCI is a standardized hydrological indicator derived from sub-monthly satellite gravity measurements and is designed to characterize the hydrological extremes at timescales of a few days.

# Reference
Tang, M., Han, S.-C., Yuan, L., Yang, X., Yeo, I.-Y., Rodell, M., Li, B., Lee, E., & Jiang, Z. (2025).
Mass Change Index for Characterizing Hydrological Extremes Every Few Days From Satellite Gravity Measurements.
Water Resources Research, 61, e2025WR040534.
